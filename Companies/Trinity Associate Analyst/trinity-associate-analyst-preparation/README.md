## Recommended study sequence

### If you have ~7 days

1. **Day 1:** `00` (process + plan), `01`, `02` — rebuild speed math + reasoning.
2. **Day 2:** `03`, `04` — DI + Excel formulas.
3. **Day 3:** `05` + `data/` datasets — hands-on Excel workflows.
4. **Day 4:** `06`, `07`, `08` — stats, business analytics, life-sciences domain.
5. **Day 5:** `09`, `16` — cases, full Relivax walkthrough.
6. **Day 6:** `14`, `15` — both timed mocks; grade with `17`.
7. **Day 7:** `11`, `12`, `13` — interview rounds; then `18` + `19` for rapid review.

### If you have ~3 days

- **Day 1:** `00`, `01`, `02`, `03`, `18` (evening revision).
- **Day 2:** `04`, `05`, `15` (Excel block), `07` quick pass.
- **Day 3:** `11`, `12`, `13`, `14` (timed), `19` evening review.

### 1-day emergency plan

- **Morning (3 h):** `18-final-revision-cheatsheet.md` cover-to-cover, then `01` + `04` only the formula tables.
- **Midday (2 h):** `15` Excel mock with the dataset open in a real spreadsheet; formulas at hand.
- **Afternoon (2 h):** `14` timed mock → grade with `17`.
- **Evening (2 h):** `11` skim model answers, `12` spoken STAR practice, `19` read all traps.
- **Skip if very short on time:** `06`, `07`, `08` deep reading — use only the one-page summaries in `18`.

## How to run the mocks

1. **Online assessment mock (`14`):** No calculator apps if the real test disallows them (check your test rules). Set a 60-minute timer. Answer all 30 questions in one sitting. Score with the key; target ≥ 75% before you consider yourself ready.
2. **Excel mock (`15`):** Open `data/trinity_excel_mock.csv` in Excel/LibreOffice/Google Sheets. 45-minute timer. Do the tasks in the file, save your workbook, then compare against the verified expected answers and grading notes.
3. **Case mock (`16`):** Read the case, spend 3 minutes structuring, then talk through your analysis out loud as if to an interviewer. Compare with the worked solution only afterwards.
