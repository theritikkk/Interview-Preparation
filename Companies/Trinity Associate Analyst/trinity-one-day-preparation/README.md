## How to use the mocks

1. **Mock A** ([`10`](10-mock-assessment-and-excel-test.md)): one sitting, 60 minutes, no answers visible until finished. Target ≥ 24/30.
2. **Mock B** ([`10`](10-mock-assessment-and-excel-test.md)): open the embedded dataset in Excel / LibreOffice / Google Sheets. 45 minutes of work, then grade against the key. Target ≥ 14/17. **Second pass:** redo it a day later importing the raw file `data/trinity_excel_mock.csv` (Data → From Text/CSV) — importing and cleaning a messy file is itself part of the assessed skill.
3. **Mock C** ([`14`](14-second-mock-assessment-mcq-60-min.md)): a second, independent 30-question assessment in **MCQ format**. One 60-minute sitting, on a different day from Mock A. Target ≥ 24/30.
4. Grade honestly, then read every wrong answer's explanation.
5. After each mock, score with [`17`](17-mock-and-interview-score-rubric.md) and log every miss by trap number in [`15`](15-errors-mistakes-and-traps.md) — a trap that appears three times is your revision priority.

> ⚠️ **Warning — do not over-trust this practice:** the *stages and durations* above are confirmed, but the **actual question format, distribution, difficulty, and cut-offs are not confirmed** for any stage. Mock A's section mix is a realistic guess (**PRACTICE**), not Trinity's blueprint. If the real test looks different, stay calm and read carefully.
