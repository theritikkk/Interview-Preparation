# Theory of Computation → Regular Languages: Minimal DFAs & Myhill–Nerode

**GATE 2027 syllabus:** Theory of Computation — regular languages, finite automata.
**Set:** 10 questions (MCQ / MSQ / NAT). Difficulty ramps from fundamental (Q1–Q2) to a killer conceptual question (Q10).
**Conventions:** Σ = {a, b} unless stated otherwise. "Minimal DFA" means the complete DFA (a transition for every state–symbol pair, including a dead/trap state where needed) with the fewest states. Two strings x, y are Myhill–Nerode equivalent for a language L if for every string z, xz ∈ L ⇔ yz ∈ L; the number of equivalence classes equals the number of states of the minimal DFA. For binary-number languages, strings are read most-significant bit first, leading zeros are allowed, and the empty string is treated as the number 0 (so it is accepted when 0 is in the language).

## Answer Key

| Q | Answer | Quick check |
|---|--------|-------------|
| 1 | B | The Myhill–Nerode characterisation of regularity |
| 2 | 4 | One state per value of |w| mod 4 |
| 3 | A, C | (B) and (D) are the classic non-regular languages (an unbounded counter is needed) |
| 4 | 3 | States: last symbol not a, last symbol a, dead state |
| 5 | C | The DFA must remember the last 3 symbols: 2³ = 8 (verified by counting Myhill–Nerode classes) |
| 6 | 6 | Product of a mod-3 counter and a mod-2 counter: 3 × 2 |
| 7 | A, B, C | (D) is false — the subset construction gives at most 2ⁿ states, often fewer |
| 8 | 5 | One state per remainder mod 5 (verified) |
| 9 | A, B, D | (C) is false — the minimal DFA has 3 states (verified); (A) 2⁴ = 16 and (D) mod-5 counter are verified |
| 10 | 4 | Remainders mod 6 collapse: for any non-empty suffix, only the remainder mod 3 matters, so {1,4} and {2,5} merge; classes are {0}, {3}, {1,4}, {2,5} (verified) |
