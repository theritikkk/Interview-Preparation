# Compiler Design → Top-Down Parsing (FIRST/FOLLOW, LL(1))

**GATE 2027 syllabus:** Compiler Design — parsing.
**Set:** 10 questions (MCQ / MSQ / NAT). Difficulty ramps from fundamental (Q1–Q2) to a killer conceptual question (Q10).
**Conventions:** FIRST(α) is the set of terminals that can begin some string derived from α (including ε if α can derive the empty string). FOLLOW(A) is the set of terminals that can immediately follow A in some derivation from the start symbol (including $ if A can be the last symbol before end-of-input). A grammar is LL(1) iff its LL(1) parsing table has no cell with more than one production (no conflicts). $ marks end-of-input.
